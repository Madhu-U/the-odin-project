# The Odin Project

My solutions and projects from [The Odin Project](https://www.theodinproject.com/), an open-source curriculum for learning web development through hands-on practice.

## About

This repository contains exercises, assignments, and projects completed throughout my web development learning journey. The focus is on building practical skills, understanding core concepts, and applying them through progressively more complex projects.

## Curriculum

My work is organized around the relevant sections of The Odin Project curriculum.

- **Foundations:** HTML, CSS, JavaScript fundamentals, Git, and introductory programming projects.
- **Full Stack JavaScript:** Further frontend development, JavaScript applications, and full-stack projects as I progress through the curriculum.

Only sections and projects I've worked on are included in this repository.
